# The Black Sepulchre Campaign Command

Веб-приложение для двухигроковой кампании Warhammer 40,000 11e по правилам The Black Sepulchre v2.0.

Текущий стек: React + TypeScript + Vite, Supabase Postgres/Auth/Realtime, GitHub Pages.

Production URL после первого успешного deployment:
https://mishokkka.github.io/Black_Sepulchre/

Публичный Supabase publishable key находится в клиенте намеренно. Service-role key в репозитории отсутствует.
